# MCP360

Hosted unified MCP gateway that exposes 100+ third-party tools to AI agents via the Model Context Protocol, with a no-code Custom MCP Builder that wraps any REST API as an MCP server, plus a conventional REST surface behind the same gateway.

## APIs

- **MCP360 Gateway** — Unified MCP gateway exposing a hosted remote MCP server, a REST API for tool metadata and execution, and an llms.txt. Authentication via API key (Bearer token for REST, ?token= for MCP). (`https://connect.mcp360.ai/api/v1`)

> MCP360 exposes a hosted remote MCP server at https://connect.mcp360.ai/v1/{service}/mcp (token-authenticated, consumed via npx mcp-remote) and a REST API at https://connect.mcp360.ai/api/v1 with Bearer-token auth (GET /api/v1/{service} for metadata, POST /api/v1/{service}/{tool_name} for execution). A valid llms.txt is confirmed live. No public OpenAPI/AsyncAPI/GraphQL/Postman contract was found at common locations. Per-tool skill-style YAML blocks are embedded in service pages but there is no downloadable/published agent-skills package or manifest endpoint. Free developer tools (MCP Inspector, MCP Config Generator, MCP Server Validator) are provided as web tools. API keys are issued via the dashboard at https://dashboard.mcp360.ai after free signup. apis.json and several derived endpoints were not directly retrievable during audit; REST/MCP details come from MCP360's live service pages.
